# Languages

Every string the server sends a player comes out of a catalogue in `base/i18n/<code>.json`:

```json
{
	"LANGUAGE_NAME": "English",
	"WELCOME": "Welcome to the server, %%."
}
```

`LANGUAGE_NAME` is what `/language` lists. `%%` placeholders are filled in order.

```ts
player.text('WELCOME', player.name);         // the string, translated
player.languageMessage('WELCOME', name);     // as a chat line
player.languageError('NO_PERMISSION');       // with the [Error] prefix
player.languageNotify('VEHICLE_LOCKED');     // as a notification
messageToAll('PLAYER_JOINED', name);         // everyone, each in their own language
```

A key missing from the player's language falls back to English, and a key missing from English comes
back as itself, so a missing translation is visible in game rather than silent. Both cases log a
warning.

The catalogues are read at resource start from the resource's own `i18n/` folder (the build copies
them there; FXServer only lets a resource read its own folder). `restart base` picks up an edit.

A player's language is chosen with `/language <name or code>` and remembered against their licence in
the resource's key-value store, so it survives a reconnect without a database.

Adding a language: add `<code>.json` with at least `LANGUAGE_NAME`, rebuild, restart.
